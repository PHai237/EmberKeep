# Lịch sử — không phải hướng dẫn hiện tại

Các tài liệu ở đây được giữ nguyên để truy vết sự phát triển từ Phase 1 tới UI v0.5. Chúng có thể chứa mô tả UI, nút bấm hoặc lệnh cũ **không còn đúng** với source hiện tại.

- `PHASE_1_REPORT.md`: kết quả và giới hạn giai đoạn nền.
- `UI_REDESIGN_REPORT.md`: UI v0.1.1.
- `CHAT_UI_RELEASE_NOTES.md`: UI v0.2 và XP/economy.
- `FOLIO_UI_V03.md`: thử UI dạng sách.
- `UI_V04_NOTES.md`, `UI_V05_NOTES.md`: các đợt làm lại giao diện.
- `CODEX_PHASE_1.md`: prompt cũ đã thực hiện, không chạy lại.

Nguồn tham chiếu hiện tại: `README.md` ở root và `docs/PROJECT_STATUS.md`.
